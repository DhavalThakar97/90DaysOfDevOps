## Key Takeaways

* `>` creates a file or overwrites existing content.
* `>>` appends new content without overwriting the file.
* `cat` displays the entire file.
* `head` shows the beginning of a file.
* `tail` shows the end of a file.
* `tee` writes to a file while displaying the output on the terminal.
